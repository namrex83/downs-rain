# Namrex Weather (namrexweather.com)

The code and data jobs behind [namrexweather.com](https://namrexweather.com): gauge-corrected radar rainfall, the
Namrex AI rain forecast, storms, wind, temperature, soil and Condamine/Brisbane river heights for the Darling Downs
and South East Queensland.
